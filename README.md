# TXSE Volume Scraper & Analytics

Automated collection and analysis of **Texas Stock Exchange (TXSE), participant code F** U.S. equity trading activity.

## What it collects

The preferred historical/backfill source is Cboe's annual **U.S. Equities Historical Market Volume** CSV. It contains daily, exchange-level data broken out by Tape A/B/C for:

- matched shares
- notional / dollar value traded
- trade count

The project also retains a current-day HTML collector and an optional NasdaqTrader Playwright cross-check.

## Files produced

`data/txse_daily.csv` stores one row per trading day with:

- total shares
- total dollar/notional volume
- total trades
- Tape A/B/C shares
- Tape A/B/C notional
- Tape A/B/C trade counts
- average dollars per share
- average shares per trade

`reports/latest.md` contains the rolling analysis generated by GitHub Actions.

## Backfill any date range

```bash
python -m txse_scraper.history --start 2026-08-10 --end 2026-08-14
```

## Analyze a date range

```bash
python -m txse_scraper.analyze \
  --start 2026-08-10 \
  --end 2026-08-14 \
  --output reports/week-2026-08-10.md
```

## Current-day collector

```bash
python -m txse_scraper.scraper
```

Optional NasdaqTrader browser cross-check:

```bash
python -m txse_scraper.scraper --nasdaq
```

## Automation

`.github/workflows/txse-volume.yml` runs at **23:35 UTC Monday-Friday**. It deliberately re-fetches a recent window rather than just the current day, which handles weekends, holidays, delayed Cboe publication, and reruns safely. The CSV is date-keyed, so duplicate dates are replaced rather than appended.

The workflow also regenerates `reports/latest.md` and commits changed data back to the repository.

## Data source

Cboe U.S. Equities Historical Market Volume. Cboe states the files are based on UTDF and CTS consolidated data feeds and include daily shares, notional value and trade counts by market center and tape. Cboe asks published reports using the data to cite Cboe Exchange, Inc.
